# 내 실험 – 요약과 상세 설명

2026년 11월 19일 · @JsonParc

발표 본편(논문 소개)에 덧붙이는 내 실험은 두 개다: ① 논문의 핵심 결과를 노트북에서 재현하는 시연, ② 논문의 한계 하나에서 출발한 머신러닝 디코딩 실험. 발표 과목이 머신러닝이므로, 두 실험 모두 "어떤 머신러닝 기법을 왜 썼고, 무엇을 보여주는가"를 중심으로 설명한다.

## 요약

**한 줄 요약:** 논문의 핵심 결과(T4/T5 방향 선택성)를 내 노트북에서 재현하고, 같은 가상 뇌의 신호를 "세포 단위"로 볼 때와 "여러 뉴런을 섞어서"(EEG처럼) 볼 때 움직임 방향을 얼마나 읽어낼 수 있는지를 수업에서 배운 머신러닝 절차(특징 추출 → 특징 선택 → 학습 → 누수 없는 교차검증)로 비교했다.

| 구분 | ① 논문 결과 재현 | ② 머신러닝 디코딩 실험 |
|---|---|---|
| 목적 | 논문 결과를 직접 확인하고 시연 | 논문이 답하지 않은 질문에 머신러닝으로 답하기 |
| 질문 | 방향 감지 뉴런이 정말 특정 방향에만 반응하나? 과제를 잘 푸는 모델일수록 실제 뇌처럼 반응하나? | 신호를 합쳐 차원을 줄이면 방향 정보가 얼마나 사라지나? 어떤 특징·채널이 그 정보를 담나? |
| 방법 | 사전학습 모델에 움직이는 막대를 보여주고 T4/T5 반응 측정, 50개 앙상블 비교 | 세포 단위 신호 vs 섞인 신호로 움직임 방향 분류 |
| 쓰는 ML | 학습된 RNN을 평가만 함(재학습 없음). 앙상블과 모델 선택(과제 손실 vs 뉴런 반응) | 특징 추출, 특징 선택(순차 전진 선택), 로지스틱 회귀·K-NN, z-score, 교차검증(nested CV), 데이터 누수 대조 실험 |
| 결과물 | T4a~d, T5a~d 극좌표 그래프 + 앙상블 산점도 + 발표 사이트의 인터랙티브 그래프 | 잡음 크기별 정확도 그래프(메인) + 특징 선택·누수 비교 그래프 |
| 발표 위치 | 논문 결과 슬라이드 안 | 논문 한계점 슬라이드 다음 |
| 비중 | 필수 | 필수 (발표의 머신러닝 핵심) |

## 실제 결과 (2026-11-19 실행, 자세한 숫자는 results/summary.md)

**① 재현**
- 검증 오차 1위 모델이 T4a~d, T5a~d 8개 하위 유형의 선호 방향을 **모두** 맞혔다(오차 45° 미만).
- 상위 10개 모델 각각으로 보면 하위 유형마다 4~8개 모델만 맞혔다 → 해가 하나로 정해지지 않는다.
- 검증 오차 순위 1–10위 모델은 평균 5.1개, 41–50위는 2.8개를 맞혔다(순위 상관 ρ = −0.32) → 과제 성능으로 모델을 고르는 것이 타당하다.

**② 디코딩 (가설 확인)**

| 잡음 | A · 65채널 | B · 4채널 | B · 1채널 |
|---|---|---|---|
| 0.1배 | 100.0% | 96.6% | 74.4% |
| 1배 | 99.9% | 84.1% | 40.3% |
| 2배 | 98.4% | 54.2% | 29.1% |

1. 세포 단위 신호가 가상 EEG보다 잘 맞힌다 → **맞음**
2. 잡음이 클수록 격차가 커진다 → **맞음** (A−B4 격차 3.4 → 15.8 → 44.2%p)
3. B4는 우연보다 잘 맞히고 B1은 우연 근처 → **절반만 맞음**. B1도 잡음 2배에서 29%로 우연(12.5%)의 2배 이상. 전체 합에도 방향마다 반응 크기·시간 차이가 남아 있다.
4. 세포 유형 몇 개면 충분하고 T4/T5가 들어 있다 → **맞음**. 3개로 98.1%, 세 fold 모두 T4a 1번째, T5d 3번째.
5. 누수가 있으면 정확도가 부풀려진다 → **실제 데이터에서는 작았고(+1.4~2.5%p)**, 정답을 섞은 가짜 데이터에서는 누수 선택이 우연의 1.8배(22.4%) "성능"을 만들어 냈다.

추가 발견: 시간 영역 특징이 PSD보다 우세(A 99.9 vs 75.1%), 분류기 셋(로지스틱 회귀·선형 SVM·K-NN)은 차이 작음, 채널 수를 4개로 맞추면 B4가 무작위 세포 유형 4개 조합의 80%보다 낫지만 잘 고른 4개(99.5%)에는 크게 못 미친다.

## ① 논문 결과 재현

- **무엇을:** 논문 결과 중 가장 직관적인 "T4/T5 방향 선택성"을 재현한다. T4는 밝은 가장자리, T5는 어두운 가장자리가 움직일 때 반응하고, 각각 4개 하위 유형(a~d)이 앞→뒤, 뒤→앞, 위, 아래 중 서로 다른 방향을 담당한다.
- **왜 이걸 고르나:** 논문이 "뉴런 측정 데이터 없이 배선도와 과제만으로 실제 뇌와 같은 계산 방식이 나타났다"고 주장하는 대표 사례다. 그림 한 장으로 결과가 보이고, 청중도 바로 이해한다.
- **머신러닝 관점:** 이 모델은 연결 구조가 커넥톰으로 고정된 순환 신경망(RNN)이다. 학습 값은 734개뿐이고(같은 세포 유형끼리 파라미터를 공유 — CNN의 가중치 공유와 같은 생각), 광류 예측이라는 대리 과제로 BPTT(시간을 펼친 역전파)와 경사 하강법으로 학습했다. 재현은 "학습에 쓰지 않은 질문(방향 선택성)에서도 실제 뇌와 맞는가" = 일반화 평가다.
- **어떻게:** 공식 사전학습 모델에 밝은 막대와 어두운 막대를 여러 방향으로 움직여 보여주고, 각 하위 유형 뉴런의 최대 반응을 방향별로 기록한다. 공식 튜토리얼 "Moving Edge Responses"를 따른다.
- **보여줄 그림:**
  - T4a~d, T5a~d 각각의 극좌표 그래프 8개. 그래프가 한쪽으로 뾰족하게 튀어나와 있으면 "그 방향만 좋아한다"는 뜻이다.
  - 앙상블 그림: 50개 모델의 과제 오차(가로축)와 방향 선택성 정도(세로축) 산점도. "과제를 잘 푸는 모델일수록 실제 뇌처럼 반응하는가" = 과제 성능으로 모델을 고르는 근거.
- **시연 흐름:** 발표는 학교 컴퓨터의 브라우저에서 하므로 모델을 그 자리에서 돌리지 않는다. 결과를 미리 계산해 발표 사이트(Render 배포)에 넣고, 방향 버튼을 누르면 그 방향의 막대 애니메이션과 극좌표 그래프가 바뀌는 인터랙티브로 보여준다. 재현 코드의 핵심 부분은 결과 그래프 옆에 나란히 띄운다.
- **주의할 점:** 50개 모델은 같은 조건으로 학습했어도 서로 다른 해에 도달하므로, 단일 모델은 일부 하위 유형을 틀릴 수 있다. 성능 상위 모델 몇 개의 결과도 함께 확인해 두고, 틀린 하위 유형이 나오면 오히려 "해답이 하나로 정해지지 않는다 → 그래서 앙상블과 모델 선택이 필요하다"는 머신러닝 포인트로 설명한다.
- **성공 기준:** 8개 하위 유형 중 대부분이 서로 다른 한 방향을 뚜렷하게 선호하는 그림이 나오면 된다.

## ② 머신러닝 디코딩 실험: 배경, 질문, 가설

**배경이 된 한계:** 논문은 세포 하나하나의 활동을 다룬다. 하지만 수업에서 배운 EEG 같은 신호는 전극 몇 개로, 그 아래 수많은 뉴런의 활동이 공간적으로 섞인 신호를 잰다. 논문은 "섞인 신호로도 뇌가 본 것을 읽어낼 수 있나"에는 답하지 않는다.

**질문 (머신러닝으로 바꾸면):** 같은 뇌의 신호를 합쳐서 차원을 줄이면(65채널 → 4채널 → 1채널), 움직임 방향을 맞히는 데 필요한 정보가 얼마나 사라질까? 그리고 정보는 어떤 채널·어떤 특징에 들어 있을까?

**왜 이 질문이 의미 있나:**

- 실제 실험에서는 같은 뇌에서 "세포 단위 신호"와 "섞인 신호"를 동시에 얻기 어렵다. 그래서 섞이면서 정보가 얼마나 사라지는지 직접 재기 어렵다.
- 가상 뇌에서는 둘 다 만들 수 있다. 정답(방향)과 원 신호를 모두 아는 상태에서 특징 추출·선택·검증을 깨끗하게 실험할 수 있는 장점이 있다.
- 수업에서 배운 신호처리(EEG)와 머신러닝(특징, 분류기, 교차검증)을 이 논문의 모델 위에서 직접 연결해 볼 수 있다.

**가설:**

1. 세포 단위 신호(A)가 섞인 신호(B)보다 움직임 방향을 잘 맞힌다.
2. 측정 잡음이 클수록 둘의 격차가 커진다.
3. 섞인 신호도 채널을 공간 구역별로 나누면(4채널) 우연 수준(12.5%)보다는 잘 맞히지만, 전체를 하나로 합치면(1채널) 우연 수준에 가까워진다.
4. 세포 유형 몇 개만 골라도(특징 선택) 대부분의 정보를 얻을 수 있고, 그 안에 T4/T5가 들어 있다.
5. 특징 선택을 전체 데이터로 하면(누수) 정확도가 실제보다 부풀려진다.

## 실험 절차 상세

수업 1장의 머신러닝 4단계(데이터 수집 → 특징 추출·선택 → 모델 학습 → 검증)를 그대로 따른다.

### STEP 1. 데이터 수집

1. **자극 만들기:** 8방향(45도 간격)으로 움직이는 밝은 막대와 어두운 막대를 속도 3단계로 만든다. 방향 8 × 밝기 2 × 속도 3 = 48가지 자극 조건이다. 8방향의 샘플 수는 모두 같다(수업 5장 표집 편향 방지).
2. **가상 뇌에 보여주기:** 학습이 끝난 flyvis를 고정한 채 각 자극을 보여주고, 모든 뉴런의 전압 시계열을 기록한다. 시뮬레이션은 같은 자극에 항상 같은 반응을 내므로 조건당 한 번이면 된다.
3. **두 종류의 신호 만들기:**
   - 신호 A (세포 단위): 세포 유형별로 뉴런 전압을 평균해 세포 유형 수만큼(약 65개) 채널을 만든다. 실험실에서 특정 세포 유형만 골라 기록하는 상황에 해당한다.
   - 신호 B (섞인 신호, 가상 EEG): 세포 유형 구분 없이 모든 뉴런의 전압을 공간 구역별로 합친다. 눈을 4구역으로 나눈 4채널 버전과, 전체를 하나로 합친 1채널 버전 두 가지다. 전극 몇 개로 넓은 영역을 뭉뚱그려 재는 EEG에 해당한다.
4. **측정 잡음 더하기:** 각 채널에 가우시안 잡음을 더해 조건당 20번 "반복 측정"한 것처럼 만든다. 잡음 크기는 채널별 신호 표준편차의 0.1배, 0.5배, 1배, 2배 네 단계다. 샘플 수는 잡음 단계마다 48 × 20 = 960개다.

### STEP 2. 특징 추출과 선택

5. **특징 추출:** 채널마다 최고 전압, 최저 전압, 최고점까지 걸린 시간, 평균 전압 4개를 뽑는다. 신호 A는 약 260개(65 × 4), 신호 B는 16개(4 × 4) 또는 4개(1 × 4) 특징이 된다.
6. **정규화:** z-score 정규화(평균 0, 표준편차 1)로 특징 크기를 맞춘다. 평균과 표준편차는 매 fold의 학습 데이터에서만 계산한다(수업 3장).
7. **특징 선택 (순차 전진 선택):** 신호 A에서 세포 유형 채널을 하나씩 추가하며 정확도 곡선을 그린다. 선택은 바깥 fold의 학습 데이터 안에서, 안쪽 교차검증으로만 한다. fold별로 뽑힌 세포 유형과 횟수를 기록해 중요한 세포 유형을 판단한다(수업 4장 래퍼 방식).

### STEP 3. 모델 학습

8. **분류기:** 로지스틱 회귀(L2 정규화)로 8방향 중 하나를 맞힌다. 신호 A, B(4채널), B(1채널) 각각에 대해, 잡음 단계마다 따로 학습한다. 비교용으로 K-NN도 학습한다. 하이퍼파라미터(정규화 세기 C, 이웃 수 k)는 안쪽 교차검증으로만 고른다.

### STEP 4. 검증

9. **교차검증:** 속도 조건 기준으로 나눈다. 두 속도로 학습하고 나머지 한 속도로 테스트하는 것을 세 번 반복(leave-one-speed-out)해서, 처음 보는 조건에서도 맞히는지 확인한다. 같은 자극의 반복 측정이 학습과 테스트에 섞이지 않는다. 특징 선택·튜닝이 들어가는 실험은 이 바깥 fold 안에서 다시 안쪽 교차검증을 하는 nested CV다.
10. **평가 지표:** 정확도(우연 수준 12.5%와 비교), fold별 평균과 표준편차, 8×8 혼동 행렬(수업 5장).
11. **누수 대조 실험:** 같은 특징 선택을 일부러 "전체 데이터로 먼저 고른 뒤 교차검증"하는 잘못된 방법으로도 돌려, 올바른 방법과 정확도 차이를 나란히 보여준다.

## 결과물과 해석 시나리오

**결과물:**

- **메인 그래프 (발표용):** 가로축은 잡음 크기(0.1·0.5·1·2배), 세로축은 정확도. 선 세 개(신호 A 65채널, 신호 B 4채널, 신호 B 1채널)와 우연 수준 12.5% 점선. 각 점에는 fold별 표준편차를 오차 막대로 표시. 발표 사이트에서는 잡음 크기 슬라이더를 움직이면 세 신호의 정확도와 혼동 행렬이 바뀌는 인터랙티브로도 보여준다.
- **머신러닝 그래프 (발표용):**
  - 특징 선택 곡선: 고른 세포 유형 수(가로축)에 따른 정확도. 올바른 방법(fold 안 선택)과 누수 있는 방법을 두 선으로 나란히.
  - 채널 수를 맞춘 비교: 신호 A에서 세포 유형 4개를 무작위로 고른 경우(여러 번 반복한 분포) vs 신호 B 4채널.
- **백업 그림:** 잡음 1배 단계의 8×8 혼동 행렬(신호 A와 B 4채널 나란히), 시간 영역 특징 vs PSD 특징, 로지스틱 회귀 vs K-NN.
- **숫자 표:** results/accuracy.csv에 조건별 정확도 평균과 표준편차.

**해석 시나리오 (어느 쪽이 나와도 발표할 수 있게 미리 준비):**

| 나온 결과 | 해석 | 발표 한 줄 |
|---|---|---|
| A와 B의 격차가 큼 | 합치면서(차원 축소) 방향 정보가 크게 사라진다 | "어떤 특징을 측정하느냐가 분류기 선택보다 중요하다" |
| A와 B의 격차가 작음 | 섞인 신호에도 방향 정보가 꽤 남아 있다 | "적은 채널로도 정보가 남는다 — 특징만 잘 뽑으면 된다" |
| B 1채널은 우연 수준, B 4채널은 그보다 높음 | 정보가 신호가 "어디서" 나오는지에 들어 있다 | "공간 정보를 남기는 채널 구성이 중요한 이유다" |
| 잡음이 커질수록 격차가 벌어짐 | 섞인 신호는 잡음에 더 취약하다 | "잡음이 많을수록 정보가 많은 특징의 가치가 커진다" |
| 세포 유형 몇 개로 정확도가 포화, T4/T5가 상위 | 방향 정보는 소수의 특정 세포에 몰려 있다 | "특징 선택이 ① 재현 결과(T4/T5)를 데이터로 다시 찾아냈다" |
| 누수 있는 선택이 정확도를 부풀림 | 선택도 학습의 일부다 | "특징 선택은 반드시 fold 안에서" |

**결과가 예상과 다를 때:** 가설이 틀려도 실패가 아니다. 예를 들어 B 1채널이 우연보다 훨씬 높게 나오면, 방향마다 전체 반응 크기나 타이밍이 달라서일 수 있다. "왜 그런지"를 혼동 행렬로 짚어 설명하면 된다.

## 설계 선택 이유

모든 선택은 "고정된 뇌에서 정보를 읽어낼 수 있나, 섞이면 얼마나 손해인가, 그걸 누수 없이 정직하게 재려면 어떻게 하나"라는 질문에서 나온다. 괄호 안은 연결되는 강의다.

1. **flyvis를 고정하고 재학습하지 않는다:** 실제 실험에서 연구자는 뇌를 바꿀 수 없고 기록만 한다. 원 논문은 디코더와 뇌를 함께 학습시켰지만, 나는 고정된 뇌를 바깥에서 관찰하는 상황을 흉내 낸다. 학습하는 것은 내 분류기뿐이다. (노트북 CPU로 재학습이 어렵다는 현실적 이유도 있다.)
2. **측정 잡음을 더한다:** 시뮬레이션은 같은 자극에 항상 같은 반응을 내서, 잡음이 없으면 정확도가 무의미하게 100%가 될 수 있다. 실제 기록 장비의 잡음을 흉내 내야 같은 부류 안에서도 흩어짐(부류 내 분산)이 생겨 현실적인 분류 문제가 된다. (4장 분별력)
3. **잡음을 한 값이 아니라 4단계로:** 잡음 크기를 하나로 정하면 그 값을 왜 골랐는지 설명하기 어렵다. 여러 단계로 바꿔가며 "잡음에 따라 결론이 어떻게 변하나"를 보여주는 편이 정직하다.
4. **과제는 움직임 방향 맞히기:** 원 논문이 검증한 핵심 기능이라 정답이 명확하고, ① 재현 시연과 자연스럽게 이어진다.
5. **섞인 신호는 4채널과 1채널 두 버전:** 1채널만 쓰면 "정보가 당연히 다 사라졌다"로 끝날 수 있어서, 공간 정보를 일부 남긴 4채널과 비교해 "어디서 오는 신호인가"의 역할까지 본다.
6. **특징은 시간 영역 특징:** 뉴런 전압은 시계열 신호지만 뇌파처럼 진동하지 않고 자극에 짧게 반응한다. 그래서 수업에서 배운 PSD보다 "언제, 얼마나 세게 반응했나"가 신호 성질에 맞는다. 이 예상은 PSD 특징과 직접 비교해 확인한다. (3장 파형 특징, 1장 "데이터 특성을 잘 반영하는 특징")
7. **z-score 정규화:** 세포 유형마다 전압 범위가 달라, 범위가 큰 특징이 분류를 좌우하지 않게 맞춘다. (3장 특징 정규화)
8. **분류기는 로지스틱 회귀:** 이진 분류라면 시그모이드 단층 퍼셉트론, 8방향 분류라면 소프트맥스 단층 퍼셉트론을 경사 하강법으로 학습하는 것과 같다. 단순한 선형 분류기로도 맞힌다면, 정보가 분류기가 아니라 뉴런 신호 자체에 들어 있다는 뜻이다. L2 정규화로 특징이 많은 신호 A의 과적합을 막는다. 비선형·거리 기반인 K-NN과 비교해 정보가 선형으로 읽히는 형태인지도 확인한다. (2장 델타 규칙·경사 하강법·정규화, 5장)
9. **속도 기준 교차검증, 전처리는 fold 안에서:** 같은 자극의 반복 측정이 학습과 테스트에 섞이거나, 전체 데이터로 정규화를 미리 하면 정확도가 부풀려진다. 처음 보는 속도로 테스트해야 진짜 일반화를 확인할 수 있다. (1장 "학습과 테스트는 완벽히 분리", 4장 Practical TIPS와 교수님 논문의 데이터 누수 문제)
10. **특징 선택·튜닝도 fold 안에서 (nested CV):** 테스트 데이터를 보고 채널이나 하이퍼파라미터를 고르는 것도 누수다. 바깥 fold는 평가만, 안쪽 fold는 선택·튜닝만 한다. 잘못된 방법의 결과도 함께 보여줘 "왜 이렇게 해야 하는가"를 숫자로 보인다. (4장 래퍼 방식, Practical TIPS)
11. **8방향 샘플 수를 똑같이:** 한 방향만 샘플이 많으면 그 방향만 찍어도 정확도가 높게 나온다. 처음부터 균형을 맞춰 정확도를 그대로 믿을 수 있게 한다. (5장 표집 편향)

## 이 실험의 독창성과 한계

### 독창성

1. **원 논문이 다루지 않은 질문:** 원 논문은 "배선도로 뇌 활동을 예측할 수 있나"를 물었다. 나는 그 다음 질문인 "그 활동이 섞이면 뇌가 본 것을 얼마나 읽어낼 수 있나, 정보는 어디에 있나"를 같은 가상 뇌로 직접 비교했다.
2. **실제 실험으로는 어려운 비교:** 같은 뇌에서 세포 단위 신호와 섞인 신호를 동시에 얻는 건 실제로는 어렵지만, 가상 뇌에서는 둘 다 만들 수 있다.
3. **원 논문과 반대 방향의 관점:** 원 논문은 디코더와 뇌를 함께 학습시켰다. 나는 뇌를 고정하고 바깥에서 관찰자로서 읽어내, 실제 실험 상황에 가깝게 만들었다.
4. **누수를 숫자로 보여줌:** 올바른 검증과 누수 있는 검증을 같은 데이터에서 나란히 비교해, 수업에서 강조한 원칙의 효과를 직접 측정했다.

### 한계 (발표에서 먼저 말하기)

1. **모델 안에서의 결론:** 실제 뇌 데이터가 아니라 시뮬레이션 결과다. 실제 뇌에 적용하려면 실측 데이터로 확인해야 한다.
2. **가상 EEG는 단순 합산:** 두피와 두개골을 지나며 생기는 신호 왜곡, 뇌 구조에 따른 신호 방향 같은 실제 EEG의 물리적 특성은 반영하지 않았다. "신호가 섞인다"는 효과만 따로 떼어 본 것이다.
3. **잡음 모델이 단순:** 실제 기록 잡음은 시간에 따라 이어지고 채널끼리 상관이 있지만, 여기서는 서로 독립인 가우시안 잡음만 썼다.
4. **서로 다른 자극이 48개뿐:** 960샘플은 48개 자극에 잡음을 입힌 반복이다. 실제로 독립인 정보는 48개 조건이라, 교차검증을 조건(속도) 단위로 나눈 것이 중요하다.
5. **초파리 시각계이지 사람 뇌가 아니다:** 회로 크기와 구조가 다르므로 수치를 사람에게 그대로 옮길 수 없다.

## 예상 질문과 답변

- **Q. 시뮬레이션 데이터로 한 실험이 의미가 있나요?**
  A. 실제 실험으로는 같은 뇌에서 세포 단위 신호와 섞인 신호를 동시에 얻기 어렵지만, 가상 뇌에서는 가능합니다. 다만 결론은 "이 모델 안에서"의 결론이고, 실제 뇌로 일반화하려면 실측 데이터 검증이 필요하다는 것을 한계로 둡니다.
- **Q. 잡음은 왜 넣었고, 크기는 어떻게 정했나요?**
  A. 시뮬레이션은 같은 자극에 항상 같은 반응을 내서, 잡음이 없으면 정확도가 무의미하게 100%가 됩니다. 크기를 하나로 정하지 않고 네 단계로 바꿔가며 결론이 어떻게 변하는지 보여드렸습니다.
- **Q. 데이터 누수는 어떻게 막았나요?**
  A. 처음 보는 속도로 테스트하도록 속도 기준으로 나눴고, 정규화·특징 선택·하이퍼파라미터 선택은 매번 학습 데이터 안에서만 했습니다(nested CV). 누수가 있을 때 정확도가 얼마나 부풀려지는지도 직접 비교해 보여드렸습니다.
- **Q. 왜 딥러닝이 아니라 로지스틱 회귀인가요?**
  A. 목표가 최고 성능이 아니라 "정보가 신호에 들어 있는가"를 보는 것이라서입니다. 단순한 선형 분류기로도 맞힌다면 정보가 신호에 명확히 들어 있다는 증거가 되고, 해석하기도 쉽습니다. 샘플도 960개뿐이라 큰 모델은 과적합 위험이 큽니다. K-NN과도 비교했습니다.
- **Q. 가상 EEG가 진짜 EEG와 같나요?**
  A. 아닙니다. 두피·두개골에서 생기는 왜곡이나 사람 뇌의 구조는 반영하지 않고, "여러 뉴런 신호가 섞인다"는 효과만 따로 떼어 본 것입니다.
- **Q. 신호 A는 채널이 65개고 B는 4개인데, 채널 수 차이 때문 아닌가요?**
  A. 맞는 지적이라 직접 확인했습니다. 신호 A에서 세포 유형 4개만 무작위로 골라 B 4채널과 비교해, 채널 수가 같을 때도 차이가 나는지 보여드립니다.
- **Q. 원 논문의 디코더와 무엇이 다른가요?**
  A. 원 논문은 광류 계산을 위해 디코더를 네트워크와 함께 학습시켰습니다. 저는 네트워크를 고정하고, 같은 뇌를 세포 단위로 볼 때와 섞어 볼 때 읽어낼 수 있는 정보가 얼마나 다른지를 물었습니다.
- **Q. 특징 선택 결과는 믿을 수 있나요?**
  A. 선택을 각 fold의 학습 데이터 안에서만 했고, fold마다 같은 세포 유형이 반복해서 뽑히는지(선택 횟수)로 안정성을 확인했습니다.

## 실험 우선순위

핵심(메인 그래프)이 끝난 뒤 위에서부터 진행한다. 1~2는 발표 본문, 3~4는 백업 슬라이드로 두고 질문이 나오면 꺼낸다.

1. **특징 선택 + 누수 대조:** 순차 전진 선택으로 "몇 종류의 뉴런이면 충분한가" 곡선. 올바른 방법과 누수 있는 방법을 나란히. T4/T5가 상위에 나오면 ① 재현 결과와도 이어진다. (수업 4장 래퍼 방식, Practical TIPS)
2. **채널 수를 맞춘 비교:** 신호 A에서 세포 유형 4개만 무작위로 골라(여러 번 반복) 신호 B 4채널과 비교한다. "채널 수가 같아도 세포별로 골라 재는 쪽이 나은가"에 답한다.
3. **시간 영역 특징 vs PSD:** 같은 신호에서 PSD 특징을 뽑아 비교한다. 반응이 진동하지 않아 PSD가 불리할 것이라는 예상을 확인한다. (수업 3장)
4. **로지스틱 회귀 vs K-NN:** 거리 기반 분류기와 비교한다. (수업 5장)
