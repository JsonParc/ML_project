# 발표 준비 — 슬라이드별 내용과 설명 대본

발표 사이트(site/index.html)의 슬라이드 순서와 같다. 각 슬라이드마다 **화면에 보이는 것**과 **말로 설명할 것**을 적었다.
숫자는 모두 이 프로젝트에서 직접 계산했거나(results/), 설치된 flyvis 코드·사전학습 모델 설정에서 확인한 값이다.

발표 순서 (6부)
1. 논문을 고른 이유
2. 이 논문만의 독창성
3. 사용한 머신러닝 모델 — 무엇이고, 왜 이 모델인가
4. 머신러닝 파이프라인
5. 논문 결과 (+ 내 노트북 재현)
6. 논문의 한계와 이를 극복하기 위한 내 아이디어 (덧붙임 실험)
+ 마무리 직전: 논문대로 직접 해 본 재현 (덧붙임)

## 1부. 논문을 고른 이유

**슬라이드 1 — 표지**: 제목, 논문 정보. 오른쪽에 겹눈 721개 기둥 위로 막대가 지나가는 애니메이션.

**슬라이드 2 — 이 논문을 고른 이유**
- 재미있는 오픈소스를 둘러보다가 초파리 뇌 지도(커넥톰)가 오픈소스로 공개됐다는 걸 봤다.
- 사람들이 그 지도로 초파리 뇌에게 게임을 시키는 등 여러 실험을 하고 있었다.
- 관련 논문을 찾다가 Nature에 실린 이 논문을 알게 됐다.
- 신호처리·머신러닝 과목에서 배우는 것(EEG 같은 뇌 신호, 딥러닝)과 연결되어 있어 골랐다.
- 말할 것: "연구 분야에서 출발한 게 아니라 재미있어 보여서 시작했다. 읽어 보니 머신러닝 수업 내용(RNN, 역전파, 교차검증, 모델 선택)이 다 들어 있었다."

## 2부. 이 논문만의 독창성

**슬라이드 3 — 풀고 싶은 문제: 배선도는 있는데 '동작'을 모른다**
- 커넥톰 = 누가 누구와 몇 개의 시냅스로 연결됐는지. 하지만 각 뉴런이 얼마나 빨리 반응하는지(시간 상수), 연결이 실제로 얼마나 센지는 모른다.
- 기존 방법 ① 전기생리 측정: 세포 유형마다 전극·칼슘 이미징으로 직접 잰다. 수십 년이 걸리고, 작은 세포는 재기도 어렵다.
- 기존 방법 ② 데이터 맞춤 모델: 측정한 반응에 모델을 맞춘다. 측정 데이터가 있는 세포에만 쓸 수 있다.
- 질문: "측정 없이, 배선도만으로 뉴런 하나하나의 활동을 예측할 수 있을까?"

**슬라이드 4 — 기존 방법과 비교표**

| | 데이터 맞춤 모델 | 기존 과제 기반 딥러닝 (예: 물체 인식 CNN으로 시각피질 설명) | 이 논문 (DMN) |
|---|---|---|---|
| 학습에 실제 뉴런 데이터 | 필요 | 불필요 | 불필요 |
| 모델 구조 | 연구자가 설계 | 일반 CNN/RNN | **커넥톰 그대로** |
| 모델 유닛 ↔ 실제 뉴런 | 일부 대응 | 대응 없음 (집단 수준 비교만) | **일대일 대응** (45,669개) |
| 검증 단위 | 맞춘 세포 | 뇌 영역 전체의 표현 | **세포 유형 하나하나** |

**슬라이드 5 — 독창성 네 가지**
1. **측정 없이 예측**: 배선도로 구조를 고정하고, 남은 값은 과제(움직임 감지)를 풀도록 학습한다. 뉴런 측정은 학습에 한 번도 쓰지 않는다.
2. **일대일 대응**: 일반 딥러닝 모델의 뉴런은 실제 뉴런과 대응하지 않는다. DMN은 모델 뉴런 하나가 특정 세포 유형의 특정 위치 뉴런이라, 실제 실험 결과와 세포 단위로 바로 비교할 수 있다.
3. **규모**: 세포 유형 65개(광수용체 포함), 뉴런 45,669개, 연결 1,513,231개를 한 모델로 (flyvis 커넥톰에서 직접 센 값).
4. **불확실성까지**: 같은 조건으로 50개를 학습해, 모델끼리 예측이 일치하는 세포(믿을 만한 예측)와 엇갈리는 세포를 구분한다.
- 말할 것: "커넥토믹스(배선도)와 딥러닝(학습)을 합쳤다는 것이 핵심. 둘 중 하나만으로는 안 되던 일을 했다."

## 3부. 사용한 머신러닝 모델

**슬라이드 6 — DMN = 연결 구조가 고정된 연속시간 RNN**
- 식 (flyvis `PPNeuronIGRSynapses` 코드와 같다):
  τ · dV/dt = −V + V_rest + Σ_j w_ij · ReLU(V_j) + 입력
  - V: 뉴런 전압 (RNN의 은닉 상태)
  - ReLU(V_j): 이웃 뉴런의 출력 (활성화 함수)
  - w_ij = 부호 × 시냅스 개수 × 세기 배율
  - 시간 간격 dt로 쪼개 오일러 방법으로 한 단계씩 계산 = RNN을 시간 축으로 펼친 것
- 일반 RNN과 대응: 은닉 상태 = 전압, 순환 가중치 행렬 = 커넥톰(희소 행렬), 활성화 = ReLU, 누설(leak) 항 −V
- 고정 값(배선도): 연결 여부, 부호(흥분/억제), 시냅스 개수
- 학습 값 734개: 시간 상수 τ 65개 + 휴지 전위 V_rest 65개(세포 유형마다) + 시냅스 세기 배율 604개(연결 종류마다)

**슬라이드 7 — 왜 이 모델인가 (귀납적 편향)**
- 일반 RNN이면 연결 151만 개 각각의 가중치를 배워야 한다 → 데이터가 엄청 필요하고, 배운 값이 실제 뇌와 대응한다는 보장이 없다.
- DMN은 같은 세포 유형끼리 값을 공유(721개 기둥 어디서나 같은 회로) → 734개만 배운다. CNN이 이미지 위치마다 같은 필터를 쓰는 가중치 공유와 같은 생각.
- 얻는 것: ① 과적합 위험이 작다 ② 배운 값(세포 유형의 시간 상수 등)을 생물학적으로 해석할 수 있다 ③ 모델 뉴런 = 실제 뉴런이라 세포 단위 검증이 가능하다.
- 연속시간 모델을 쓴 이유: 실제 뉴런은 시간에 따라 전압이 변하고, 움직임 감지는 "언제" 신호가 오는지(시간 차이)가 핵심이다.
- ReLU: 시냅스는 전압이 일정 이상일 때만 신호를 보낸다는 성질을 단순하게 표현.

**슬라이드 8 — 디코더: 작은 육각 CNN**
- 입력: DMN 출력 세포 유형들의 전압(ReLU로 음수 제거) — 721개 기둥 위의 지도
- 구조(flyvis `DecoderGAVP`, 사전학습 설정): 5×5 육각 합성곱 → 8채널 → BatchNorm → Softplus → Dropout 0.5 → 5×5 육각 합성곱 → 광류 2채널(가로·세로 속도)
- 왜 작게? 디코더가 크면 디코더가 혼자 문제를 풀어 버린다. 작게 두면 움직임 계산을 DMN(뇌 모델)이 맡게 된다.
- Dropout, BatchNorm: 수업에서 배운 과적합 방지·학습 안정화 기법 그대로.

## 4부. 머신러닝 파이프라인

**슬라이드 9 — 학습 파이프라인 (사전학습 모델 설정 파일 기준)**
1. 데이터: Sintel 애니메이션 영화의 장면과 정답 광류(각 픽셀이 어디로 움직였는지). 19프레임 조각, 50 Hz(dt = 20 ms).
2. 전처리: 영상을 겹눈 721개 육각 픽셀로 변환(박스 필터).
3. 데이터 증강: 좌우·상하 뒤집기·회전(확률 0.5), 대비·밝기 무작위 변화, 가우시안 잡음(0.08), 무작위 시간 자르기 → 적은 데이터로 일반화.
4. 순전파: 광수용체 입력 → DMN 시뮬레이션 → 디코더 → 광류 예측.
5. 손실: 예측 광류와 정답 광류의 L2 거리 + 뉴런 활동이 비정상적으로 커지지 않게 하는 정규화 항.
6. 역전파: 시간을 펼친 역전파(BPTT)로 734개 값과 디코더 가중치의 기울기 계산 → Adam으로 갱신. 배치 4, 25만 번 반복.
7. 검증: 데이터를 4개 fold로 나누고 학습에 쓰지 않은 fold로 검증 손실 계산 → 가장 좋은 체크포인트 저장.
8. 앙상블: 같은 설정으로 50번 학습 → 검증 손실로 순위 매김(모델 선택).
9. 최종 평가: 학습에 전혀 쓰지 않은 실제 뉴런 측정과 비교. 맞추기(fitting) 없이 그대로 비교한다.

**슬라이드 10 — 머신러닝 관점에서 본 핵심**
- 지도학습이지만 "뉴런의 정답"은 없다 → 대리 과제(proxy task)
- 평가는 학습과 완전히 다른 분포(실제 뉴런 데이터)에서 → 가장 엄격한 일반화 테스트
- 모델 선택 근거: 과제 손실이 낮은 모델일수록 실제 뇌와 더 비슷한가? → 5부에서 직접 확인

## 5부. 논문 결과

논문이 보인 결과를 설명한다. 숫자는 논문 공식 코드(flyvis)에 들어 있는 비교용 실측 데이터에서 직접 센 값만 쓴다.

**슬라이드 11 — 무엇과 비교했나**
- 학습이 끝난 모델에 실험실 자극(깜빡이는 빛, 움직이는 가장자리)을 보여 주고 세포 유형마다 실제 실험 결과와 비교. 실험 결과에 다시 맞추는 과정(fitting)은 없다.
- 비교한 성질: ON/OFF 극성(알려진 유형 24개: ON 10, OFF 14), 방향 선택성(18개: 선택적 8, 비선택적 10), T4/T5 방향 튜닝 곡선(Maisak et al. 2013)
- 머신러닝으로 보면: 학습(영화 → 광류)과 테스트(실험실 자극 → 뉴런 반응)가 완전히 다른 분포 밖 일반화 테스트.

**슬라이드 12 — 아무도 가르치지 않았는데 방향 감지 세포가 생겼다**
- 왼쪽: 실제 측정된 T4a–d, T5a–d 튜닝 곡선. 하위 유형마다 한 방향만 좋아한다.
- 모델은 광류만 맞히도록 학습했는데, 모델 안 T4/T5가 같은 방향 선택성을 갖게 됐다. 방향 선택성이 없다고 알려진 10개 유형(Mi1, Tm3 등)은 모델에서도 거의 없었다.
- 근거(공개 모델로 직접 확인): 과제 손실 상위 10개 모델의 DSI 중앙값 — 방향 선택적 8개 유형 0.52, 비선택적 10개 유형 0.02
- 말할 것: "배선도가 할 수 있는 계산의 범위를 정하고, 과제가 그중 무엇을 할지 정한다."

**슬라이드 13 — 앙상블과 모델 선택**
- 같은 설정으로 50번 학습해도 세포 유형에 따라 모델마다 반응이 다르다(해가 하나가 아니다).
- 세포 유형마다 50개 모델의 반응을 UMAP으로 차원 축소·군집화해 해의 종류를 본다(비지도 학습으로 결과 해석).
- 과제 검증 손실이 낮은 모델일수록 실제 측정과 잘 맞는 경향 → 뉴런 데이터를 보지 않고 과제 성능으로 모델을 고른다.
- 흐름: 50번 학습 → 검증 손실로 순위 → 상위 모델로 예측 → 실제 측정과 비교(테스트는 마지막에 한 번)

**슬라이드 14 — 측정되지 않은 세포에 대한 예측**
- 광수용체를 뺀 57개 유형 중 ON/OFF가 알려진 것은 24개, 모르는 것 33개.
- 모델 뉴런 = 실제 세포 유형이라, 아직 기록되지 않은 유형에 대해서도 반응을 예측한다. 앙상블이 일치하면 믿을 만한 예측, 엇갈리면 실험이 필요한 곳 → 무엇을 먼저 측정할지 알려 주는 도구.
- 5부 정리 상자.

## 6부. 한계와 극복 아이디어

**슬라이드 15 — 논문의 한계 네 가지**
1. 세포 단위 활동만 다룬다 → 섞인 신호(EEG 등)로도 읽어낼 수 있는지 모른다
2. 해가 하나로 정해지지 않는다
3. 단순한 뉴런 모델 (스파이크 없음, 즉각 전달 시냅스)
4. 과제가 광류 하나
- 아래 상자: 1번을 극복할 아이디어를 직접 시험해 봤다(덧붙임). 2~4번은 재학습이 필요한데 노트북 CPU로는 어렵다.

**슬라이드 16 — 한계 극복 아이디어 (덧붙임 실험)**
- 학습된 모델을 고정된 녹화 장치로 써서, 같은 뇌에서 세포 단위 신호(A, 65채널)와 섞인 신호(B, 4구역 4채널 / 전체 1채널)를 만들고 움직임 방향 8개를 분류.
- 설계 한 줄: 48개 자극 × 잡음 20번, 시간 영역 특징, 로지스틱 회귀, 속도 기준 교차검증, 정규화·특징 선택은 학습 fold 안에서만.

**슬라이드 17 — 결과 (잡음 슬라이더)**
- 섞으면 손실: 잡음 1배 99.9% → 84.1% → 40.3% (우연 12.5%)
- 특징 선택: 세포 유형 3개로 98.1%, 세 fold 모두 T4a·T5d 선택 → 5부의 방향 감지 세포를 데이터가 다시 찾음
- 채널 종류가 중요: 잘 고른 세포 4개 99.5% ≫ 4구역 84.1% > 무작위 세포 4개 68.6%
- 누수 확인: 정답을 섞은 데이터에서 테스트 정답을 보고 특징을 고르면 22.4%의 가짜 성능
- 자세한 그래프는 부록 C~G.

## 덧붙임과 마무리

**슬라이드 18 — 논문대로 직접 해 보기 (인터랙티브)**
- "논문을 읽고 직접 해 보면 재밌을 것 같아서, 공개된 코드와 모델 50개로 공식 튜토리얼과 같은 자극을 노트북에서 돌려 봤다."
- 과제 손실 1위 모델은 8개 하위 유형 모두 정답. 1–10위 모델 평균 5.1개 vs 41–50위 2.8개 → 논문이 말한 "모델마다 다른 해", "과제 성능으로 고르기"가 그대로 보였다.
- 방향 버튼, 밝은/어두운, 최고 모델/상위 10개 각각 전환.

## 예상 질문과 답

- **시뮬레이션 데이터로 한 실험이 의미 있나요?** 실제로는 같은 뇌에서 세포 단위 신호와 섞인 신호를 정답과 함께 동시에 얻기 어렵다. 가상 뇌라서 가능한 비교이고, 결론은 "이 모델 안에서"의 결론이라고 한계로 밝혔다.
- **왜 딥러닝 분류기가 아니라 로지스틱 회귀인가요?** 목표는 최고 성능이 아니라 "정보가 신호에 있는가"를 보는 것. 선형 분류기로 맞히면 정보가 신호에 있다는 증거가 된다. 샘플도 960개(서로 다른 자극은 48개)뿐이라 큰 모델은 과적합 위험이 크다. K-NN, 선형 SVM과도 비교했고 차이가 작았다.
- **채널 수 차이 때문 아닌가요?** 무작위 4개 유형 200번과 비교했다(부록 E).
- **잡음 크기는 어떻게 정했나요?** 하나로 정하지 않고 4단계로 바꿔가며 결론이 어떻게 변하는지 보였다.
- **데이터 누수는 어떻게 막았나요?** 속도 기준 fold, 정규화·특징 선택·하이퍼파라미터 선택을 모두 학습 fold 안에서(Pipeline + nested CV). 누수가 있을 때 결과도 직접 비교했다.
- **원 논문의 디코더와 무엇이 다른가요?** 원 논문은 광류를 계산하려고 디코더를 뇌 모델과 함께 학습했다. 나는 뇌 모델을 고정하고, 바깥에서 관찰자로서 신호의 종류에 따라 읽어낼 수 있는 정보가 얼마나 다른지 물었다.
- **왜 1위 모델 하나로만 녹화했나요?** 과제 오차 1위가 생물학적으로도 가장 정확했다(8/8). 여러 모델로 반복하는 것은 남은 과제(한계에 적음).
