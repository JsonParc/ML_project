============================================================
용어 정리
============================================================

발표에 나오는 용어를 분야별로 정리. 각 용어마다 뜻, 개념 설명, 이 논문(또는 추가 실험)에서 어떻게 쓰이는지 순서로 적음.

목차
1. 신경과학 기초
2. 초파리 시각계
3. 논문의 모델
4. 학습 방법
5. 평가와 분석
6. 머신러닝 일반 개념
7. 추가 실험 관련 (신호처리, 검증)

============================================================
1. 신경과학 기초
============================================================

[뉴런 (neuron)]
----------------------------------------
신경계에서 정보를 전달하는 세포. 다른 뉴런에게서 신호를 받아 전압이 변하고, 그 변화를 다시 다음 뉴런에 전달함.
- 이 논문에서는 뉴런 하나를 "전압 하나"로 단순화해서 다룸.

[막전위, 전압 (membrane potential)]
----------------------------------------
뉴런 세포막 안팎의 전압 차이. 다른 뉴런에서 흥분성 신호를 받으면 올라가고(탈분극), 억제성 신호를 받으면 내려감(과분극).
- 모델의 상태 변수 V가 이 값. 단위는 실제 mV가 아니라 임의 단위.

[휴지 전위 (resting potential)]
----------------------------------------
아무 입력이 없을 때 뉴런이 유지하는 기본 전압. 입력이 끊기면 전압은 이 값으로 돌아감.
- 모델에서 세포 유형마다 하나씩 학습하는 값(65개). 신경망의 편향(bias)과 같은 역할.

[시간 상수 (time constant, τ)]
----------------------------------------
입력이 바뀌었을 때 전압이 새 값으로 따라가는 속도를 나타내는 값. τ가 작으면 빠르게, 크면 천천히 반응.
- 모델에서 세포 유형마다 하나씩 학습하는 값(65개). 움직임 감지에는 세포마다 반응 속도가 다른 것이 중요함.

[시냅스 (synapse)]
----------------------------------------
뉴런과 뉴런이 신호를 주고받는 연결 부위. 두 뉴런 사이에 시냅스가 여러 개 있을 수 있고, 개수가 많을수록 영향이 큼.
- 흥분성 시냅스: 받는 뉴런의 전압을 올림
- 억제성 시냅스: 받는 뉴런의 전압을 내림
- 모델에서 연결 가중치 = 부호(흥분 +1 / 억제 −1) × 시냅스 개수 × 세기 배율. 부호와 개수는 커넥톰에서 가져오고, 세기 배율만 학습.

[탈분극 / 과분극 (depolarization / hyperpolarization)]
----------------------------------------
전압이 휴지 전위보다 올라가는 것이 탈분극, 내려가는 것이 과분극. 일반적으로 탈분극이 "반응했다"는 뜻.
- 부록 A 영상에서 빨강 = 탈분극, 파랑 = 과분극.

[스파이크 (spike, 활동 전위)]
----------------------------------------
많은 뉴런이 전압이 일정 수준을 넘으면 순간적으로 크게 튀는 신호를 내보냄. 초파리 시각엽의 많은 뉴런은 스파이크 대신 전압이 연속적으로 변하는 방식(graded potential)으로 신호를 전달함.
- 이 논문의 모델은 스파이크를 다루지 않음 (한계 3번).

[커넥톰 (connectome)]
----------------------------------------
뇌 안의 모든 뉴런과 그 연결(시냅스)을 정리한 지도. 전자현미경으로 뇌 조직을 아주 얇게 잘라 찍은 뒤 뉴런을 하나하나 추적해서 만듦. "배선도"라고 부르기도 함.
- 커넥톰으로 알 수 있는 것: 누가 누구와 연결됐는지, 시냅스 개수, (신경전달물질로 추정한) 흥분/억제
- 커넥톰으로 알 수 없는 것: 시간 상수, 휴지 전위, 실제 연결 세기
- 이 논문은 커넥톰을 모델의 구조로 그대로 사용.

[커넥토믹스 (connectomics)]
----------------------------------------
커넥톰을 만들고 분석하는 연구 분야.

[전기생리학 측정, 칼슘 이미징]
----------------------------------------
뉴런 활동을 직접 재는 실험 방법.
- 전기생리학 측정: 미세 전극을 뉴런에 꽂아 전압을 직접 기록
- 칼슘 이미징: 뉴런이 활동할 때 세포 안 칼슘 농도가 올라가는 것을 형광 단백질로 보이게 해서 현미경으로 촬영
- 둘 다 세포 유형마다 따로 실험해야 해서 시간과 비용이 많이 듦. 이 논문이 "측정 없이 예측"하려는 이유.

[세포 유형 (cell type)]
----------------------------------------
모양, 연결 패턴, 기능이 같은 뉴런들의 묶음. 예: T4a, Mi1, L1.
- 이 논문은 세포 유형 64개(광수용체 R1–R8 포함)를 다룸. 모델 내부에서는 CT1을 두 구획(CT1(Lo1), CT1(M10))으로 나눠 65개로 다루며, 유형마다 721개 또는 123개의 뉴런이 있음. 시간 상수·휴지 전위가 각각 65개인 이유.

============================================================
2. 초파리 시각계
============================================================

[겹눈 (compound eye)]
----------------------------------------
작은 눈(낱눈) 수백 개가 모여 만들어진 곤충의 눈. 낱눈 하나가 시야의 한 점을 담당하므로, 겹눈 전체는 육각형 픽셀로 된 카메라처럼 동작함.

[기둥 (column)]
----------------------------------------
낱눈 하나에 대응하는 뇌 속 신경 회로 단위. 각 기둥에 같은 세포 유형 구성이 반복됨.
- 이 모델은 721개 기둥을 육각 격자 위에 배치. 기둥마다 같은 회로가 반복되는 것이 파라미터 공유의 근거.

[육각 격자 (hexagonal lattice)]
----------------------------------------
기둥들이 벌집 모양으로 배열된 구조. 좌표는 (u, v) 두 개의 축으로 표현.
- 모델 입력도 일반 이미지(정사각 픽셀)가 아니라 721개 육각 픽셀.

[광수용체 (photoreceptor, R1–R8)]
----------------------------------------
빛을 받아 전기 신호로 바꾸는 세포. 시각 정보의 입력 단계.
- 모델에서 입력 자극은 광수용체에 들어감.

[시각엽 (optic lobe)]
----------------------------------------
겹눈 뒤에 있는 시각 정보 처리 영역. 라미나, 메둘라, 로뷸라 등의 층으로 이루어짐.
- 이 논문은 시각엽 중 움직임을 처리하는 경로를 모델링.

[ON 경로 / OFF 경로]
----------------------------------------
- ON 경로: 빛이 밝아지는 변화를 처리하는 세포들 (예: Mi1, Tm3, T4)
- OFF 경로: 빛이 어두워지는 변화를 처리하는 세포들 (예: Tm1, Tm9, T5)
- 사람 망막에도 비슷한 구분이 있음.

[ON/OFF 극성 (polarity)]
----------------------------------------
세포가 밝아짐(ON)과 어두워짐(OFF) 중 어디에 반응하는지. 논문 평가 항목 중 하나.

[움직임 감지 (motion detection)]
----------------------------------------
시야에서 무언가가 어느 방향으로 움직이는지 계산하는 것. 한 지점의 밝기 변화와 이웃 지점의 밝기 변화가 시간 차이를 두고 일어나는 것을 비교해서 방향을 알아냄.

[T4 / T5 세포]
----------------------------------------
초파리에서 움직임 방향을 감지하는 대표적인 세포.
- T4: 밝은 가장자리(ON)의 움직임에 반응
- T5: 어두운 가장자리(OFF)의 움직임에 반응
- 각각 하위 유형 a, b, c, d가 있고, 하위 유형마다 앞→뒤, 뒤→앞, 위, 아래 중 한 방향만 담당. flyvis 기준 선호 방향: a 180°, b 0°, c 90°, d 270°.

[방향 선택성 (direction selectivity)]
----------------------------------------
특정 방향의 움직임에만 강하게 반응하는 성질. T4, T5는 방향 선택적이고, Mi1, Tm3 등은 방향 선택적이지 않음.

[선호 방향 (preferred direction)]
----------------------------------------
방향 선택적 세포가 가장 강하게 반응하는 움직임 방향.

[방향 튜닝 곡선 (tuning curve)]
----------------------------------------
움직임 방향(가로축 또는 각도)별로 반응 크기를 그린 그래프. 극좌표로 그리면 선호 방향 쪽으로 튀어나온 모양이 됨.
- 실측 곡선: Maisak et al. (2013), Nature 500.

[광류 (optical flow)]
----------------------------------------
영상에서 각 위치가 다음 순간에 어느 방향으로 얼마나 움직이는지를 나타낸 벡터 지도. 위치마다 (가로 속도, 세로 속도) 두 값.
- 이 논문의 학습 과제. 모델이 영상을 보고 광류를 맞히도록 학습함.

============================================================
3. 논문의 모델
============================================================

[DMN (Deep Mechanistic Network)]
----------------------------------------
이 논문의 모델 이름. "Mechanistic"은 실제 생물학적 구조(커넥톰)와 동작 원리(뉴런 전압 방정식)를 따른다는 뜻이고, "Deep"은 딥러닝 방식으로 학습한다는 뜻.

[연속시간 RNN (continuous-time recurrent neural network)]
----------------------------------------
상태가 미분방정식으로 시간에 따라 연속적으로 변하는 순환 신경망.
- DMN의 식: τ · dV/dt = −V + V_rest + Σ w · ReLU(V_이웃) + 입력
- 실제 계산은 시간을 작은 간격(dt)으로 쪼개 한 단계씩 진행 → 일반 RNN을 시간 축으로 펼친 것과 같은 구조.

[오일러 적분 (Euler method)]
----------------------------------------
미분방정식을 컴퓨터로 푸는 가장 단순한 방법. 다음 값 = 현재 값 + dt × 변화율.
- 학습 시 dt = 20 ms (50 Hz).

[은닉 상태 (hidden state)]
----------------------------------------
RNN이 시간 단계마다 기억하는 내부 값. 다음 단계 계산에 다시 쓰임.
- DMN에서는 뉴런 45,669개의 전압.

[순환 가중치 행렬 (recurrent weight matrix)]
----------------------------------------
은닉 상태끼리 서로 영향을 주는 정도를 담은 행렬.
- DMN에서는 커넥톰. 연결이 없는 곳은 0인 희소 행렬(연결 1,513,231개).

[고정 파라미터 / 학습 파라미터]
----------------------------------------
- 고정: 연결 여부, 시냅스 부호, 시냅스 개수 (커넥톰에서 가져옴)
- 학습: 시간 상수 65개 + 휴지 전위 65개 + 시냅스 세기 배율 604개 = 734개 (DMN만의 수. 디코더 파라미터 7,427개는 별도로 함께 학습)

[파라미터 공유 (parameter sharing, weight sharing)]
----------------------------------------
여러 위치에서 같은 파라미터를 함께 쓰는 것. CNN이 이미지 모든 위치에 같은 필터를 쓰는 것이 대표적.
- DMN은 같은 세포 유형이면 721개 기둥 어디에 있든 같은 시간 상수, 휴지 전위를 씀. 연결 세기도 "세포 유형 A → 세포 유형 B" 종류마다 하나.

[귀납적 편향 (inductive bias)]
----------------------------------------
학습 전에 모델 구조에 미리 넣어 둔 가정. 데이터만으로는 정해지지 않는 부분을 가정으로 채워서 적은 데이터로도 학습되게 함.
- 예: CNN의 "가까운 픽셀끼리 관련 있고, 같은 패턴은 어디서나 같다"는 가정
- DMN의 귀납적 편향: "연결 구조는 커넥톰과 같고, 같은 세포 유형은 같은 성질을 가진다"

[디코더 (decoder)]
----------------------------------------
모델 내부 상태를 읽어 원하는 출력으로 바꾸는 부분.
- 이 논문의 디코더: DMN 출력 세포들의 전압 → 광류. 5×5 육각 합성곱 2층(중간 8채널)의 작은 CNN.

[육각 합성곱 (hexagonal convolution)]
----------------------------------------
육각 격자 위에서 하는 합성곱. 정사각 필터에서 육각형 모양 밖의 가중치를 0으로 가려(mask) 구현.

[앙상블 (ensemble)]
----------------------------------------
같은 문제를 푸는 모델 여러 개를 함께 쓰는 것. 결과를 평균 내거나, 모델 간 일치도로 신뢰도를 판단함.
- 이 논문: 같은 설정으로 50개 모델 학습. 공개된 사전학습 모델이 이 50개.

[사전학습 모델 (pretrained model)]
----------------------------------------
이미 학습이 끝난 모델 파라미터. 재학습 없이 불러와 바로 사용 가능.
- 논문 저자들이 50개 모델을 공개(flyvis). 재현과 추가 실험은 이 모델을 그대로 사용.

[flyvis]
----------------------------------------
논문의 공식 파이썬 라이브러리. 모델 정의, 학습 코드, 사전학습 모델, 평가 자극(깜빡임, 움직이는 가장자리 등), 비교용 실측 데이터가 들어 있음.

============================================================
4. 학습 방법
============================================================

[과제 기반 학습 (task-driven learning)]
----------------------------------------
모델이 어떤 과제를 잘 풀도록 학습시키고, 그 결과 내부 표현이 뇌와 비슷해지는지 보는 접근.
- 이 논문: 광류 예측 과제로 학습 → 내부 뉴런이 실제 뉴런과 비슷하게 반응하는지 확인.

[대리 과제 (proxy task)]
----------------------------------------
진짜 관심 대상(뉴런 반응)을 직접 학습하지 않고, 관련 있는 다른 과제(광류)로 학습하는 것.

[Sintel 데이터셋]
----------------------------------------
애니메이션 단편 영화 "Sintel"로 만든 광류 데이터셋. 장면마다 정답 광류가 있어 광류 알고리즘 평가에 많이 쓰임.
- 이 논문의 학습 데이터. 영상을 721개 육각 픽셀로 변환해 19프레임씩 사용.

[데이터 증강 (data augmentation)]
----------------------------------------
학습 데이터를 변형해서 양을 늘리는 것. 과적합을 줄이고 일반화를 높임.
- 이 논문: 상하좌우 뒤집기와 회전(확률 0.5), 대비·밝기 무작위 변화, 가우시안 잡음(σ 0.08), 무작위 시간 자르기.

[손실 함수 (loss function)]
----------------------------------------
모델 예측이 정답과 얼마나 다른지를 숫자 하나로 나타낸 것. 학습은 이 값을 줄이는 방향으로 진행.
- 이 논문: 예측 광류와 정답 광류의 L2 거리 + 뉴런 활동 정규화 항.

[L2 거리 (L2 norm)]
----------------------------------------
두 벡터 차이의 제곱합의 제곱근. 일반적인 직선 거리.

[정규화 항 (regularization term)]
----------------------------------------
손실에 더해서 모델이 원치 않는 방향으로 가지 않게 하는 항.
- 이 논문: 뉴런 활동이 비정상적으로 커지지 않게 하는 항.

[역전파 (backpropagation)]
----------------------------------------
출력의 오차를 거꾸로 전달하면서 각 파라미터가 오차에 얼마나 기여했는지(기울기)를 계산하는 방법.

[BPTT (Backpropagation Through Time, 시간 펼친 역전파)]
----------------------------------------
RNN을 시간 단계마다 펼쳐 놓으면 층이 아주 많은 일반 신경망처럼 볼 수 있음. 여기에 역전파를 적용하는 것이 BPTT.
- 이 논문: 19프레임에 걸친 DMN 시뮬레이션 전체를 펼쳐 734개 파라미터와 디코더의 기울기를 계산.

[경사 하강법 (gradient descent)]
----------------------------------------
기울기의 반대 방향으로 파라미터를 조금씩 바꿔 손실을 줄이는 방법.

[Adam]
----------------------------------------
경사 하강법의 한 종류. 파라미터마다 최근 기울기의 평균과 크기를 기억해서 학습 속도를 자동 조절함. 딥러닝에서 가장 많이 쓰는 최적화 방법 중 하나.

[배치 (batch), 반복 (iteration)]
----------------------------------------
- 배치: 한 번 갱신할 때 사용하는 데이터 묶음. 이 논문은 4개.
- 반복: 파라미터 갱신 횟수. 이 논문은 250,000번.

[체크포인트 (checkpoint)]
----------------------------------------
학습 중간중간 저장한 모델 파라미터. 검증 손실이 가장 낮았던 체크포인트를 최종 모델로 사용.

============================================================
5. 평가와 분석
============================================================

[검증 손실 (validation loss)]
----------------------------------------
학습에 쓰지 않은 검증 데이터에서 계산한 손실. 모델이 처음 보는 데이터에서도 잘 하는지 확인하는 용도.
- 이 논문: 학습 데이터를 4개 fold로 나누고 학습에 쓰지 않은 fold로 검증. "과제 손실", "과제 오차"라고도 부름.

[분포 밖 일반화 (out-of-distribution generalization)]
----------------------------------------
학습 데이터와 성질이 다른 데이터에서도 잘 동작하는 것.
- 이 논문: 학습은 영화 장면 → 광류, 평가는 실험실 자극(깜빡임, 가장자리) → 뉴런 반응.

[깜빡임 자극 (flash stimulus)]
----------------------------------------
회색 화면 중앙에 원형 빛을 일정 시간 밝게 또는 어둡게 바꾸는 자극. ON/OFF 극성을 알아보는 데 씀.

[FRI (Flash Response Index)]
----------------------------------------
깜빡임 자극에 대한 반응으로 ON/OFF를 판단하는 지표.
- FRI = (밝아질 때 최대 반응 − 어두워질 때 최대 반응) / (두 값의 합)
- +1에 가까우면 ON 세포, −1에 가까우면 OFF 세포.

[움직이는 가장자리 (moving edge)]
----------------------------------------
화면의 밝은 부분과 어두운 부분의 경계가 한 방향으로 이동하는 자극. 밝은 가장자리(ON)와 어두운 가장자리(OFF)가 있음. 방향 선택성 측정에 씀.

[DSI (Direction Selectivity Index, 방향 선택성 지수)]
----------------------------------------
방향 선택성을 0~1 숫자로 나타낸 지표.
- 방향마다 반응 크기를 길이로, 방향을 각도로 하는 벡터를 만들어 모두 더함
- DSI = 더한 벡터의 길이 / 반응 크기의 합
- 모든 방향에 똑같이 반응하면 벡터가 상쇄돼 0, 한 방향에만 반응하면 1
- 더한 벡터의 방향 = 선호 방향

[실측 데이터 (ground truth)]
----------------------------------------
실제 실험으로 측정해서 알려진 값. 모델 예측을 평가하는 기준.
- flyvis에 포함된 비교 데이터: ON/OFF 극성이 알려진 24개 유형, 방향 선택성 여부가 알려진 18개 유형, T4/T5 튜닝 곡선.

[UMAP (Uniform Manifold Approximation and Projection)]
----------------------------------------
고차원 데이터를 2차원 같은 저차원으로 줄이는 비선형 차원 축소 방법. 가까운 데이터끼리는 줄인 뒤에도 가깝게 유지되도록 함. t-SNE와 비슷한 용도.
- 이 논문: 세포 유형마다 50개 모델의 자연 영상 반응을 2차원으로 줄여, 비슷한 반응을 보이는 모델끼리 모이는지 확인.

[가우시안 혼합 모델 (Gaussian Mixture Model, GMM)]
----------------------------------------
데이터가 여러 개의 정규분포(가우시안)가 섞여서 생겼다고 보고, 각 점이 어느 분포에서 왔는지 추정하는 군집화 방법. K-평균과 비슷하지만 군집 모양이 타원형이어도 되고, 확률로 소속을 표현함.
- 이 논문: UMAP으로 줄인 점들을 GMM으로 군집화.

[BIC (Bayesian Information Criterion)]
----------------------------------------
모델이 데이터를 얼마나 잘 설명하는지와 모델이 얼마나 복잡한지를 함께 고려한 점수. 낮을수록 좋음. 군집 수를 늘리면 데이터는 더 잘 맞지만 복잡해지므로, BIC로 적당한 군집 수를 고름.
- 이 논문: 군집 수 2~5개 중 BIC가 가장 낮은 것을 선택.

[모델 선택 (model selection)]
----------------------------------------
여러 후보 모델 중 하나(또는 일부)를 고르는 것. 테스트 데이터로 고르면 테스트 성능이 부풀려지므로, 검증 데이터로 골라야 함.
- 이 논문: 실측 뉴런 데이터 대신 과제 검증 손실로 모델을 고름.

[순위 상관 (Spearman 상관계수, ρ)]
----------------------------------------
두 변수의 값 자체가 아니라 순위끼리의 상관. −1~1. 한쪽이 클수록 다른 쪽이 작으면 음수.
- 재현 결과: 과제 손실과 맞힌 하위 유형 수의 순위 상관 ρ = −0.32 (손실이 낮을수록 더 많이 맞힘).

============================================================
6. 머신러닝 일반 개념
============================================================

[RNN (Recurrent Neural Network, 순환 신경망)]
----------------------------------------
이전 시간의 은닉 상태를 다음 시간 계산에 다시 쓰는 신경망. 시계열·영상처럼 순서가 있는 데이터를 처리.

[피드포워드 신경망 (feedforward neural network)]
----------------------------------------
입력이 층을 한 방향으로 한 번 통과해 출력이 나오는 신경망. 이전 입력에 대한 기억(상태)이 없음. MLP, 일반 CNN이 여기에 해당.
- RNN과의 차이: RNN은 이전 시점의 상태를 다음 계산에 다시 써서 시간에 따른 변화를 표현함. DMN이 RNN인 이유는 뉴런 전압이 이전 시점 전압과 이웃 뉴런의 이전 출력에 의존하기 때문.

[일반화 (generalization)]
----------------------------------------
학습에 쓰지 않은 새로운 데이터에서도 잘 동작하는 능력. 머신러닝 모델 평가의 핵심. 학습 데이터 성능만 높고 새 데이터에서 낮으면 과적합.
- 이 논문: 영화 장면으로 학습하고, 실험실 자극에 대한 뉴런 반응으로 평가. 학습 분포와 다른 데이터에서의 일반화(분포 밖 일반화)를 확인한 것.

[CNN (Convolutional Neural Network, 합성곱 신경망)]
----------------------------------------
작은 필터를 입력 전체에 밀면서 같은 연산을 반복하는 신경망. 위치가 달라도 같은 패턴을 같은 방식으로 처리(가중치 공유).

[활성화 함수 (activation function)]
----------------------------------------
신경망의 각 유닛 출력에 적용하는 비선형 함수. 비선형이 있어야 복잡한 관계를 학습할 수 있음.
- ReLU: max(0, x). 음수는 0, 양수는 그대로. DMN에서 "전압이 0보다 클 때만 다음 뉴런에 신호를 보낸다"는 의미.
- Softplus: log(1 + eˣ). ReLU를 부드럽게 만든 함수. 디코더에서 사용.
- 시그모이드: 1 / (1 + e⁻ˣ). 0~1 사이 값. 로지스틱 회귀의 출력.
- 소프트맥스: 여러 클래스 점수를 합이 1인 확률로 바꾸는 함수. 다중 분류에 사용.

[과적합 (overfitting)]
----------------------------------------
학습 데이터에는 잘 맞지만 새 데이터에서는 성능이 떨어지는 현상. 파라미터가 너무 많거나 데이터가 적을 때 생김.

[Dropout]
----------------------------------------
학습 중 일부 유닛을 무작위로 꺼서(이 논문은 50%) 특정 유닛에 의존하지 않게 하는 과적합 방지 방법.

[BatchNorm (배치 정규화)]
----------------------------------------
층의 출력을 배치 단위로 평균 0, 분산 1에 가깝게 맞추는 것. 학습을 안정시키고 빠르게 함.

[지도학습 / 비지도학습]
----------------------------------------
- 지도학습: 정답(라벨)이 있는 데이터로 학습. 예: 광류 예측, 방향 분류
- 비지도학습: 정답 없이 데이터 구조를 찾음. 예: UMAP, GMM 군집화

[하이퍼파라미터 (hyperparameter)]
----------------------------------------
학습으로 정해지지 않고 사람이 미리 정하는 값. 예: 학습률, 배치 크기, 정규화 세기 C, K-NN의 k.

============================================================
7. 추가 실험 관련 (신호처리, 검증)
============================================================

[EEG (뇌파)]
----------------------------------------
두피에 붙인 전극으로 뇌의 전기 활동을 측정한 신호. 전극 하나가 그 아래 수많은 뉴런의 활동이 합쳐진 신호를 잼. 비침습적이지만 개별 뉴런 정보는 섞여 있음.
- 추가 실험의 "가상 EEG": 모델 뉴런 전압을 구역별로 단순히 더한 신호. 두피·두개골에 의한 신호 왜곡은 반영하지 않음.

[디코딩 (decoding)]
----------------------------------------
신경 신호에서 자극이나 행동 정보를 거꾸로 알아내는 것. 예: 뇌 신호로 본 움직임 방향 맞히기.
- 추가 실험: 세 종류 신호(65채널, 4채널, 1채널)로 막대 움직임 방향 8개를 분류.

[채널 (channel)]
----------------------------------------
따로 기록되는 신호 하나. EEG에서는 전극 하나.

[측정 잡음 (measurement noise)]
----------------------------------------
측정 장비나 환경 때문에 신호에 섞이는 원치 않는 값.
- 추가 실험: 시뮬레이션은 잡음이 없어서, 채널마다 독립 가우시안 잡음(신호 표준편차의 0.1/0.5/1/2배)을 더함.

[우연 수준 (chance level)]
----------------------------------------
아무 정보 없이 찍었을 때 기대되는 정확도. 8방향 분류면 1/8 = 12.5%.

[특징 추출 (feature extraction)]
----------------------------------------
원본 신호에서 분류에 쓸 값을 뽑아내는 것.
- 추가 실험의 시간 영역 특징: 채널마다 최고 전압, 최저 전압, 최고점까지 걸린 시간, 평균 전압.

[PSD (Power Spectral Density, 파워 스펙트럼 밀도)]
----------------------------------------
신호에 각 주파수 성분이 얼마나 강하게 들어 있는지를 나타낸 것. 진동하는 신호(예: 뇌파의 알파파)를 분석할 때 많이 씀.
- 추가 실험: Welch 방법으로 6개 주파수 대역의 파워를 특징으로 씀. 뉴런 전압 반응은 진동보다 짧은 반응이라 시간 영역 특징보다 정확도가 낮았음.

[Welch 방법]
----------------------------------------
신호를 겹치는 구간으로 나눠 각각 주파수 분석을 한 뒤 평균 내서 PSD를 안정적으로 추정하는 방법.

[특징 선택 (feature selection)]
----------------------------------------
가진 특징 중 분류에 쓸모 있는 것만 고르는 것.
- 순차 전진 선택 (sequential forward selection): 아무것도 없는 상태에서 정확도를 가장 많이 올리는 특징을 하나씩 추가. 분류기 성능으로 특징을 평가하므로 래퍼(wrapper) 방식.
- 추가 실험: 세포 유형(4개 특징 묶음) 단위로 선택.

[정규화 (normalization), z-score]
----------------------------------------
특징마다 범위가 다르면 큰 값의 특징이 분류를 좌우하므로 범위를 맞추는 것. z-score = (값 − 평균) / 표준편차.
- 평균과 표준편차는 학습 데이터에서만 계산해야 함(아니면 누수).

[로지스틱 회귀 (logistic regression)]
----------------------------------------
특징의 가중합을 시그모이드(이진)나 소프트맥스(다중)로 확률로 바꿔 분류하는 선형 분류기. 단층 퍼셉트론과 같은 구조.
- L2 정규화: 가중치 제곱합에 벌점을 줘서 가중치가 너무 커지지 않게 함(과적합 방지). C는 정규화 세기의 역수.

[K-NN (K-최근접 이웃)]
----------------------------------------
새 샘플과 가장 가까운 학습 샘플 k개의 다수결로 분류. 학습 단계가 거의 없는 비모수 방법.

[선형 SVM (Support Vector Machine)]
----------------------------------------
두 클래스 사이 경계와 가장 가까운 샘플 간 거리(마진)를 최대로 하는 선형 분류기.

[교차검증 (cross-validation)]
----------------------------------------
데이터를 여러 부분(fold)으로 나눠, 하나씩 돌아가며 테스트에 쓰고 나머지로 학습하는 평가 방법.
- leave-one-speed-out: 추가 실험에서 속도 3개 중 하나를 테스트로 빼고 나머지 둘로 학습(3 fold). 같은 자극의 반복 측정이 학습과 테스트에 동시에 들어가지 않게 하기 위함.
- nested CV (중첩 교차검증): 바깥 교차검증은 성능 평가만, 안쪽 교차검증(학습 데이터 안에서)은 특징 선택·하이퍼파라미터 선택만 담당.

[데이터 누수 (data leakage)]
----------------------------------------
테스트 데이터의 정보가 학습이나 모델 선택 과정에 들어가서 성능이 실제보다 높게 나오는 것.
- 예: 전체 데이터로 정규화, 테스트 정답을 보고 특징 선택, 같은 자극의 반복 측정이 학습·테스트에 섞임
- 추가 실험: 정답을 무작위로 섞은 데이터에서도 테스트 정답을 보고 특징을 고르면 22.4%(우연 12.5%)가 나옴.

[혼동 행렬 (confusion matrix)]
----------------------------------------
실제 클래스(행)와 예측 클래스(열)의 조합별 개수를 표로 나타낸 것. 어떤 클래스끼리 헷갈리는지 볼 수 있음.

[표집 편향 (sampling bias)]
----------------------------------------
클래스별 샘플 수가 다르면 많은 클래스만 찍어도 정확도가 높게 나오는 문제.
- 추가 실험: 8방향 모두 120개로 맞춤.
